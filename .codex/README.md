# Codex Workspace Guide

This directory mirrors the useful guidance from `.github/` for Codex sessions.

- `instructions.md` contains repository-wide implementation rules.
- `best-practices.md` captures review, validation, issue, translation, and release practices.
- `agents/frontend-developer.md` adapts the GitHub frontend agent for Codex work.

When repository behavior changes, update `.github/` and `.codex/` together so human, GitHub, and Codex workflows stay aligned.
